# Syndrix backend dependencies — EXACT PINS, deliberately.
#
# Do NOT loosen these back to `>=` without a ceiling. Unpinned ranges caused two
# separate production crash-loops in one deploy: an older `mcp` 1.x crashed on the
# stringified annotations from `from __future__ import annotations` in
# app/mcp_tools/*.py, then `mcp` 2.0.0 removed the `mcp.server.fastmcp` module the
# whole app is built on. Both were invisible locally because the dev venv was
# installed at a different time than the Docker image was built.
#
# To upgrade: change the version here, rebuild with `--no-cache`, and verify the
# container actually starts before pushing. Versions below match the known-good
# development venv.
