Record a Payment on an Invoice
POST
https://external-integrations.mycase.com/v1/invoices/{id}/payments

Record an individual payment on an invoice.

Request
Path Parameters
id
string
required

The id of the invoice to record a payment for.

Body
application/json
application/json
amount
number
required

The amount paid on the invoice.

date
string
required

The date of the payment. Must be in ISO 8601 date format.

notes
string

Any notes associated with this payment. Recommended to specify where this payment came from.

Responses
200

OK

Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/invoices/{id}/payments \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "amount": 0,
  "date": "string",
  "notes": "string"
}'
