Delete an Individual Task
DELETE
https://external-integrations.mycase.com/v1/tasks/{id}

Allows you to delete a specfic task, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the task you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/tasks/{id} \
  --header 'Content-Type: application/json'
