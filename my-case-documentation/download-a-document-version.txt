Download a Document Version
GET
https://external-integrations.mycase.com/v1/documents/{id}/versions/{version_number}/data

Download a specific document version.

Request
Path Parameters
id
string
required

The id of the document to download a version of.

version_number
string
required

The number of the specific version of this document to download.

Responses
302

Found

Headers
Location
string

Temporary URL to download document data (valid for 1 hour)

Request Sample: Shell / cURL
curl --request GET \
  --url https://external-integrations.mycase.com/v1/documents/{id}/versions/{version_number}/data
