Get an Individual Note
GET
https://external-integrations.mycase.com/v1/notes/{id}

Allows you to view a specfic note, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the note you want to view or update.

Responses
200

OK

Body
application/json
application/json
id
number

A unique identifier for the note.

subject
string

Subject of the note.

note
string

The body text of the note.

archived
boolean

Whether or not the note is archived.

date
string or null

The date of the note.

client
object or null

The client associated with this note, if there is one.

id
number
company
object or null

The company associated with this note, if there is one.

id
number
case
object or null

The case associated with this note, if there is one.

id
number
created_by
object

The staff member who created this note.

id
number
updated_by
object

The staff member who updated this note.

id
number
created_at
string

The date the note was created in ISO 8601 date/time format.

updated_at
string

The date the note was updated in ISO 8601 date/time format.

curl --request GET \
  --url https://external-integrations.mycase.com/v1/notes/{id} \
  --header 'Accept: application/json'
