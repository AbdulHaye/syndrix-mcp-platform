Create a Time Entry
POST
https://external-integrations.mycase.com/v1/time_entries

Create an individual time entry.

Request
Body
application/json
application/json
activity_name
string
required

The activity name associated with this time entry.

description
string
billable
boolean

Whether or not this time entry is billable.

string
required

The entry date of this time entry in ISO 8601 date format.

rate
number
required

The rate in dollars associated with this time entry.

hours
number
required

The duration in hours associated with this time entry.

flat_fee
boolean

Whether or not this time entry is a flat fee.

case
object
required

The case associated with this time entry.

id
integer
staff
object
required

The staff member associated with this time entry.

id
integer
utbms_activity_code
string

The UTBMS Activity Code (LEDES Code Set II, 1999B) for this time entry. Only accepted when LEDES billing is enabled for the firm; requires utbms_task_code to also be set. See the UTBMS Codes guide for the full list of valid codes.

utbms_task_code
string

The UTBMS Task Code (LEDES Code Set II, 1999B) for this time entry. Only accepted when LEDES billing is enabled for the firm; may be set without utbms_activity_code. See the UTBMS Codes guide for the full list of valid codes.
