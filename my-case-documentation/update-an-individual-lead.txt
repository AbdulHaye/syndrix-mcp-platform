Update an Individual Lead
PUT
https://external-integrations.mycase.com/v1/leads/{id}

Allows you to edit a specfic lead, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the lead you want to view or update.

Body
application/json
application/json
email
string

The email of the lead.

first_name
string
required

The first name of the lead.

middle_initial
string

The middle name (or initial) of the lead.

last_name
string
required

The last name of the lead.

address
AddressRequest

If you provide any address object then all address properties need to be included.

address1
string
address2
string
city
string
state
string
zip_code
string
country
string
cell_phone_number
string

The leads cell phone number.

work_phone_number
string

The leads work phone number.

home_phone_number
string

The leads home phone number.

lead_details
string

Any additional information associated to a particular lead. It is seen by other firm members but is not visible to the individual lead.

birthdate
string

The leads date of birth in ISO-8601 date format.

drivers_license_number
string

The leads drivers license number.

drivers_license_state
string

The leads drivers license state.

referral_source
string
deprecated

Deprecated. Please use the referral_source_reference field instead.

referral_source_reference
object

The referral source to associate with this lead.

id
integer
referred_by
object

If the lead was referred by another client or company in the system you would use this object.

id
integer

The ID of the existing client or company in mycase. If it does not match, we default to none.

custom_field_values
array[CustomFieldValueRequest]

Specify values for custom fields that have parent_type of client.

custom_field
object
required

The custom field that this value is associated with.

value
string or number or boolean
required

The value of this custom field.

Responses
204

No Content
