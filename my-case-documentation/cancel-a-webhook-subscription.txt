Cancel a Webhook Subscription
DELETE
https://external-integrations.mycase.com/v1/webhooks/subscriptions/{id}

Allows you to cancel a specific webhook subsciption.

Request
Path Parameters
id
string
required

The id of the webhook subscription to cancel.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/webhooks/subscriptions/{id} \
  --header 'Content-Type: application/json'
