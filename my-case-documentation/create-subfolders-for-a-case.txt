Create Subfolders for a Case
POST
https://external-integrations.mycase.com/v1/cases/{id}/subfolders

Create subfolders for a specified case.

Request
Path Parameters
id
string
required

The id of the case you want to add subfolders to.

Body
application/json
application/json
path
string
required

The relative path of this folder. Any folders listed in this path will be created automatically if they are not already in MyCase.

Example:
example_folder1/example_folder2
Responses
200

OK

Body
application/json
application/json
responses

200

name
string

created_at

Example:
/v1/folders/1
Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/cases/{id}/subfolders \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "path": "example_folder1/example_folder2"
}'
