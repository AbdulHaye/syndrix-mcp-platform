Delete an Individual Expense
DELETE
https://external-integrations.mycase.com/v1/expenses/{id}

Allows you to delete a specfic expense, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the expense you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/expenses/{id} \
  --header 'Content-Type: application/json'
