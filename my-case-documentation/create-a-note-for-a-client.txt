Create a Note for a Client
POST
https://external-integrations.mycase.com/v1/clients/{id}/notes

Create a note for a specified client.

Request
Path Parameters
id
string
required

The id of the client you want to get or create notes for.

Body
application/json
application/json
subject
string
required

Subject of the note.

note
string
required

The body text of the note.

date
string
required

The date of the note in ISO 8601 date/time format.

Responses
200

OK
