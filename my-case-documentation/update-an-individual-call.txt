Update an Individual Call
PUT
https://external-integrations.mycase.com/v1/calls/{id}

Allows you to edit a specfic call, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the call you want to view or update.

Body
application/json
application/json
called_at
string
required

An ISO 8601 timestamp of when the call happened.

caller_phone_number
string
required

The caller's phone number.

call_for
object
required

The staff member that this call is associated with.

id
integer
case
object

The case that this call is assoicated with.

id
integer
message
string
required

A description of the call.

caller_name
string
required

The caller's name. This field is mutually exclusive with fields client and lead. It is required to provide only one of the three.

client
object
required

The client that this call is associated with. This field is mutually exclusive with fields caller_name and lead. It is required to provide only one of the three.

id
integer
lead
object
required

The lead that this call is associated with. This field is mutually exclusive with fields client and caller_name. It is required to provide only one of the three.

id
integer
call_type
string

One of "incoming" or "outgoing". If no call type is added, we default to incoming.

resolved
boolean

Whether or not this call should show as resolved. Default is false.

Responses
204

No Content

curl --request PUT \
  --url https://external-integrations.mycase.com/v1/calls/{id} \
  --header 'Content-Type: application/json' \

  "caller_phone_number": "string",
  "call_for": {
    "id": 0
  },
  "case": {
    "id": 0
  },
  "message": "string",
  "caller_name": "string",
  "client": {
    "id": 0
  },
  "lead": {
    "id": 0
  },
  "call_type": "string",
  "resolved": true
}'
