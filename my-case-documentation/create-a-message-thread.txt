Create a Message Thread
POST
https://external-integrations.mycase.com/v1/message_threads

Create an individual message thread.

Request
Body
application/json
application/json
subject
string
required

The subject of the message thread.

first_message_body
string
required

The body text of the first message in the thread.

sender
object

The sender of the first message in this message thread.

id
integer
client_recipients
array[object]

Any clients you want associated with this message thread.

id
integer

The ID of the client to associate with the message thread.

staff_recipients
array[object]

Any staff you want associated with this message thread.

id
integer

The ID of the staff to associate with the message thread.

Responses
201

Created

Body
application/json
application/json
