Delete an Individual Case Stage
DELETE
https://external-integrations.mycase.com/v1/case_stages/{id}

Allows you to delete a specfic case stage, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the case stage you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/case_stages/{id} \
  --header 'Content-Type: application/json'
