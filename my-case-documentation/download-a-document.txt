Download a Document
GET
https://external-integrations.mycase.com/v1/documents/{id}/data

Download a specific document.

Request
Path Parameters
id
string
required

The id of the document to download

Responses
302

Found

Headers
Location
string

Temporary URL to download document data (valid for 1 minute)

Request Sample: Shell / cURL
curl --request GET \
  --url https://external-integrations.mycase.com/v1/documents/{id}/data
