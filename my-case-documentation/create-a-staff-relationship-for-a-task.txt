Create a Staff Relationship for a Task
POST
https://external-integrations.mycase.com/v1/tasks/{id}/relationships/staff

Create a staff relationship for a specified task.

Request
Path Parameters
id
string
required

The id of the task you want to add staff to.

Body
application/json
application/json
staff
array[object]

A list of staff to add to the task.

id
integer
required
Responses
204

No Content

Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/tasks/{id}/relationships/staff \
  --header 'Content-Type: application/json' \
  --data '{
  "staff": [
    {
      "id": 0
    }
  ]
}'
