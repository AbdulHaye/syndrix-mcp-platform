Get an Individual Client (Person)
GET
https://external-integrations.mycase.com/v1/clients/{id}

Allows you to view a specfic client (person), based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the client (person) you want to view or update.

Responses
200

OK

Body
application/json
application/json
id
integer

The unique ID of the client.

email
string

The email of the client.

first_name
string

The first name of the client.

middle_initial
string
deprecated

[DEPRECATED] This field has been replaced by the middle_name field for consistency. Please use the middle_name field instead. Use of both fields will result in an error.

middle_name
string

The middle name of the client.

last_name
string

The last name of the client.

address
AddressNestedResponse
address1
string
address2
string
city
string
state
string
zip_code
string
country
string
cell_phone_number
string

The clients cell phone number.

work_phone_number
string

The clients work phone number.

home_phone_number
string

The clients home phone number.

fax_phone_number
string

The clients fax phone number.

contact_group
string
deprecated

The client's contact group. This has been deprecated. Please use the people_group field instead.

people_group
object

The people group associated with this client.

id
integer
notes
string

Any additional information associated to a particular client. It is seen by other firm members but is not visible to the individual client.

birthdate
string

The clients date of birth in ISO-8601 date format.

archived
boolean

A True or False to let you know if the client has been archived and is no longer available for use.

cases
array[CaseNestedResponse]

Any cases associated with the client, can be one or multiple.

id
integer

The ID of the case.

custom_field_values
array[CustomFieldValueResponse]
custom_field
object

The custom field that this value is associated with. By default, this object will only be returned with an id field. To specify more fields to be returned, please see the field query parameters.

value
string or number or boolean

The value of this custom field.

created_at
string

An ISO 8601 timestamp of when the Custom Field value was created.

updated_at
string

An ISO 8601 timestamp of when the Custom Field value was last updated.

updated_at
string

When the client was last updated.

created_at
string

When the client was created.
