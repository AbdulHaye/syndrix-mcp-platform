Add List Options to a Custom Field
POST
https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options

Add list options to a custom field.

Request
Path Parameters
id
string
required

The id of the custom field you want to view or update.

Body
application/json
application/json
list_options
array[object]

List options to add to this custom field.

option_value
string
required

The name of the list option.

Responses
200

OK

Body
application/json
application/json
responses
/
200
array of:
key
string

The unique key identifier for this list option.

option
string

The name of this list option.

created_at
string

An ISO 8601 timestamp of when the list option was created.

updated_at
string

An ISO 8601 timestamp of when the list option was last updated.

Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "list_options": [
    {
      "option_value": "string"
    }
  ]
}'
