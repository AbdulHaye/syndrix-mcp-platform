Create a Custom Field
POST
https://external-integrations.mycase.com/v1/custom_fields

Create an individual custom field.

Request
Body
application/json
application/json
name
string
required

The name of the Custom Field.

parent_type
string
required

The parent resource type of the Custom Field. One of case | client | company | expense | time | time_and_expense.

field_type
string
required

The field type of the Custom Field. One of short_text | long_text | numeric | boolean | date | list | currency.

list_options
array[object]

If field_type is specified as list, this field must be provided with an array of list options.

option_value
string
required

The name of the list option.

Responses
201

Created

Body
application/json
application/json
