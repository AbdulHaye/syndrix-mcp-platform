Delete an Individual Document Version
DELETE
https://external-integrations.mycase.com/v1/documents/{id}/versions/{version_number}

Allows you to delete a specific version of a document, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the document you want to view or update.

version_number
string
required

The number of the specific version of this document.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/documents/{id}/versions/{version_number} \
  --header 'Content-Type: application/json'
