Delete an Individual Case
DELETE
https://external-integrations.mycase.com/v1/cases/{id}

Allows you to delete a specfic case, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the case you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/cases/{id} \
  --header 'Content-Type: application/json'
