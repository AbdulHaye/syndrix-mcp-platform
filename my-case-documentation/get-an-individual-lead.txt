Get an Individual Lead
GET
https://external-integrations.mycase.com/v1/leads/{id}

Allows you to view a specfic lead, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the lead you want to view or update.

Responses
200

OK

Body
application/json
application/json
id
integer

The unique ID of the lead.

email
string

The email of the lead.

first_name
string

The first name of the lead.

middle_initial
string

The middle name (or initial) of the lead.

last_name
string

The last name of the lead.

address
AddressNestedResponse
address1
string
address2
string
city
string
state
string
zip_code
string
country
string
cell_phone_number
string

The leads cell phone number.

work_phone_number
string

The leads work phone number.

home_phone_number
string

The leads home phone number.

lead_details
string

Any additional information associated to a particular lead. It is seen by other firm members but is not visible to the individual lead.

birthdate
string

The leads date of birth in ISO-8601 date format.

drivers_license_number
string

The leads drivers license number.

drivers_license_state
string

The leads drivers license state.

status
string

The current status of the lead.

approved
boolean

Whether or not this lead is approved.

referral_source
string
deprecated

Deprecated. Please use the referral_source_reference field instead.

referral_source_reference
object

The referral source associated with this lead.

id
integer
referred_by
object

If the lead was referred by another client or company in the system you would use this object.

id

The ID of the existing client or company in mycase.

custom_field_values

custom_field
object

The custom field that this value is associated with. By default, this object will only be returned with an id field. To specify more fields to be returned, please see the field query parameters.

value
string or number or boolean

The value of this custom field.

created_at
string

An ISO 8601 timestamp of when the Custom Field value was created.

An ISO 8601 timestamp of when the Custom Field value was last updated.

updated_at

When the lead was last updated.

created_at
string

When the lead was created.
