Update an Individual Event
PUT
https://external-integrations.mycase.com/v1/events/{id}

Allows you to edit a specfic event, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the event you want to view or update.

Body
application/json
application/json
name
string
required

The name of this event.

description
string
start
string
required

The start date/time of this event. Must be in ISO 8601 date format.

end
string
required

The end date/time of this event. Must be in ISO 8601 date format.

all_day
boolean

Whether or not this is an all day event.

private
boolean

Whether or not this is a private event.

location
object

The location associated with this event, if there is one.

id
number
case
object

The case associated with this event, if there is one.

id
integer
staff
array[object]
required

All staff associated with this event.

id
integer
required
boolean

Whether or not this staff member will be marked as required to attend on this event.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request PUT \
  --url https://external-integrations.mycase.com/v1/events/{id} \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "string",
  "description": "string",
  "start": "string",
  "end": "string",
  "all_day": true,
  "private": true,
  "location": {
    "id": 0
  },
  "case": {
    "id": 0
  },
  "staff": [
    {
      "id": 0,
      "required": true
    }
  ]
}'
