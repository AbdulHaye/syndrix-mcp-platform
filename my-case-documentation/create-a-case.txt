Create a Case
POST
https://external-integrations.mycase.com/v1/cases

Create an individual case.

Request
Body
application/json
application/json
name
string
required

The name of the case. The case name gets validated against our system so it must be unique.

case_number
string

An identifier the firm would like to use for this case. It is recommended the intentifier be unique but is not required.

opened_date
string

The date the case was created/opened, must be in ISO-8601 date format.

case_stage
string

The stage the case is currently in. It must match the name of the stage in the mycase system (not case sensitive), if it does not match it will default to blank.

practice_area
string

The practice area for this case. Practice area must match what is in the mycase system (not case sensitive), if it does not, we default to blank.

description
string

A description for the case.

sol_date
string

The statue of limitations date for the case, must be in ISO-8601 date (do not include ISO time).

status
string

The status of the case. One of open or closed.

outstanding_balance
number

The outstanding balance of this case.

billing_contact

The billing contact for this case.

The ID of the client or company to assign as the billing contact for this case.

case_rate
string or null

The applicable hourly rate for this staff member on this case. The source of this value is indicated by rate_type. May be null when the case is configured to use a rate plan but no matching rate plan is assigned.

rate_type
string

Indicates which rate source case_rate was resolved from. "default rate" means the staff member's personal default hourly rate is used. "case rate" means a rate override was configured specifically for this staff member on this case. "rate plan rate" means the rate was looked up from the rate plan assigned to this case, using the staff member's job title (falling back to the rate plan's default rate if no matching title is found).

Allowed values:
default rate
case rate
rate plan rate
