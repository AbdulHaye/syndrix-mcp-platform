Delete an Individual Call
DELETE
https://external-integrations.mycase.com/v1/calls/{id}

Allows you to delete a specfic call, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the call you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/calls/{id} \
  --header 'Content-Type: application/json'
