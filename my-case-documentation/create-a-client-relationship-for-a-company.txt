Create a Client Relationship for a Company
POST
https://external-integrations.mycase.com/v1/companies/{id}/relationships/clients

Create a client relationship for a specified company.

Request
Path Parameters
id
string
required

The id of the company you want to add clients to.

Body
application/json
application/json
clients
array[object]

A list of clients to add to the company.

>= 1 items
id
integer
Responses
204

No Content

Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/companies/{id}/relationships/clients \
  --header 'Content-Type: application/json' \
  --data '{
  "clients": [
    {
      "id": 0
    }
  ]
}'
