Delete an Individual Event
DELETE
https://external-integrations.mycase.com/v1/events/{id}

Allows you to delete a specfic event, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the event you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/events/{id} \
  --header 'Content-Type: application/json'
