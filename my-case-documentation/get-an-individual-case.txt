Get an Individual Case
GET
https://external-integrations.mycase.com/v1/cases/{id}

Allows you to view a specfic firm case, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the case you want to view or update.

Query Parameters
field[client]
array

A comma separated list of fields to be included on each of the clients in the response.

Example:
?field[client]=id,first_name,last_name
field[custom_field]
array

A comma separated list of fields to be included on each of the custom fields in the response.

Example:
?field[custom_field]=id,field_type
Responses
200

OK

A boolean that lets you know if the staff member associated to this case is the lead lawyer. This field is not required on a case.

boolean

A boolean that lets you know if the staff member associated to this case is the originating lawyer. This field is not required on a case.

case_rate
string or null

The applicable hourly rate for this staff member on this case. The source of this value is indicated by rate_type. May be null when the case is configured to use a rate plan but no matching rate plan is assigned.

rate_type
string

Indicates which rate source case_rate was resolved from. "default rate" means the staff member's personal default hourly rate is used. "case rate" means a rate override was configured specifically for this staff member on this case. "rate plan rate" means the rate was looked up from the rate plan assigned to this case, using the staff member's job title (falling back to the rate plan's default rate if no matching title is found).

Allowed values:
default rate
case rate
rate plan rate
