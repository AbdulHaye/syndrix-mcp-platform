Create a Webhook Subscription
POST
https://external-integrations.mycase.com/v1/webhooks/subscriptions

Create a webhook subscription.

Request
Body
application/json
application/json
model
string
required

The model to receive updates for. One of case | client | company | event | lead | message.

url
string
required

The url where updates should be sent.

actions
array[string]
required

The actions to receive updates for. You may specify any or all of created | updated | deleted.

Responses
201

Created

Body
application/json
application/json
responses
/
201
id
string

A unique identifier for the webhook subscription.

model
string

The model this subsciption will receive updates for.

url
string

The url where updates will be sent.

actions
array[string]

The actions that updates will be received for. Any or all of created | updated | deleted.

hmac_key
string

The hmac_key is the shared secret used to generate a cryptographic hash (HMAC) that ensures the integrity and authenticity of our webhook data. Please handle it securely to prevent unauthorized data transmission.

Request Sample: Shell / cURL
curl --request POST \
  --url https://external-integrations.mycase.com/v1/webhooks/subscriptions \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "string",
  "url": "string",
  "actions": [
    "string"
  ]
}'
