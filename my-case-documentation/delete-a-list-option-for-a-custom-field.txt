Delete a List Option for a Custom Field
DELETE
https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options/{key}

Delete a specific list option on a custom field.

Request
Path Parameters
id
string
required

The id of the custom field you want to view or update.

key
string
required

The unique key identifier of the list option to update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options/{key} \
  --header 'Content-Type: application/json'
