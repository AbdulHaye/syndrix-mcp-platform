Update an Individual People Group
PUT
https://external-integrations.mycase.com/v1/people_groups/{id}

Allows you to edit a specfic people group, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the people group you want to view or update.

Body
application/json
application/json
name
string
required

The name of the people group.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request PUT \
  --url https://external-integrations.mycase.com/v1/people_groups/{id} \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "string"
}'
