Update an Individual Task
PUT
https://external-integrations.mycase.com/v1/tasks/{id}

Allows you to edit a specfic task, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the task you want to view or update.

Body
application/json
application/json
name
string
required

The name of this task.

description
string
priority
string
required

The priority of this task. One of (Low | Medium | High)

due_date
string
required

The due date of this task. Must be in ISO 8601 date format.

completed
boolean

Whether or not this task is completed.

case
object

The case associated with this task, if there is one.

id
integer
staff
array[object]
required

All staff associated with this task.

id
integer
Responses
204

No Content

Request Sample: Shell / cURL
curl --request PUT \
  --url https://external-integrations.mycase.com/v1/tasks/{id} \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "string",
  "description": "string",
  "priority": "string",
  "due_date": "string",
  "completed": true,
  "case": {
    "id": 0
  },
  "staff": [
    {
      "id": 0
    }
  ]
}'
