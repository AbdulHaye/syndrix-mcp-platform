Get Invoice Payments
GET
https://external-integrations.mycase.com/v1/invoice_payments

Get all firm invoice payments viewable by the authorized user.

Request
Query Parameters

string

Filters the response to return only resources that match the filter provided.

Example:

number

The ability to specify the number of resources that are returned per response page.

>= 1
<= 1000

25
