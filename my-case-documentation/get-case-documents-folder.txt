Get Case Documents Folder
GET
https://external-integrations.mycase.com/v1/cases/{id}/folder

Get the folder for a case that contains all of the associated case documents and subfolders.

Request
Path Parameters
id
string
required

The id of the case you want the document folder for.

Responses
200

OK

Body
application/json
application/json
id
integer
name
string

The name of the folder.

created_at
string
updated_at
string
self_url
string

The url that can be used to view this folder specifically.

Example:
/v1/folders/1
Request Sample: Shell / cURL
curl --request GET \
  --url https://external-integrations.mycase.com/v1/cases/{id}/folder \
  --header 'Accept: application/json'
