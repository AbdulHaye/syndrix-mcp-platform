Delete an Individual Note
DELETE
https://external-integrations.mycase.com/v1/notes/{id}

Allows you to delete a specfic note, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the note you want to view or update.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request DELETE \
  --url https://external-integrations.mycase.com/v1/notes/{id} \
  --header 'Content-Type: application/json'
