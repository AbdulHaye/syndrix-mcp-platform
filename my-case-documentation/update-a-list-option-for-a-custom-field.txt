Update a List Option for a Custom Field
PUT
https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options/{key}

Update the name of a specific list option on a custom field.

Request
Path Parameters
id
string
required

The id of the custom field you want to view or update.

key
string
required

The unique key identifier of the list option to update.

Body
application/json
application/json
option_value
string
required

The new name for this list option.

Responses
204

No Content

Request Sample: Shell / cURL
curl --request PUT \
  --url https://external-integrations.mycase.com/v1/custom_fields/{id}/list_options/{key} \
  --header 'Content-Type: application/json' \
  --data '{
  "option_value": "string"
}'
