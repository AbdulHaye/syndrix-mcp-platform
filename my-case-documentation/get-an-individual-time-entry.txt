Get an Individual Time Entry
GET
https://external-integrations.mycase.com/v1/time_entries/{id}

Allows you to view a specfic time entry, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the expense you want to view or update.

Responses
200

OK

Body
application/json
application/json
id
integer
activity_name
string

The activity name associated with this time entry.

description
string
billable
boolean

Whether or not this time entry is billable.

entry_date
string

The entry date of this time entry in ISO 8601 date format.

rate
string

The rate in dollars associated with this time entry.

hours
number

The duration in hours associated with this time entry.

flat_fee
boolean

Whether or not this time entry is a flat fee.

case
object
id
integer
staff

id
integer
utbms_activity_code
string

The UTBMS Activity Code (LEDES Code Set II, 1999B) associated with this time entry, if present. See the UTBMS Codes guide for the full list of valid codes.

utbms_task_code
string

The UTBMS Task Code (LEDES Code Set II, 1999B) associated with this time entry, if present. See the UTBMS Codes guide for the full list of valid codes.

invoices
