Update an Individual Location
PUT
https://external-integrations.mycase.com/v1/locations/{id}

Allows you to edit a specfic location, based on the authorized user/firm priviledges.

Request
Path Parameters
id
string
required

The id of the location you want to view or update.

Body
application/json
application/json
name
string
required

The name of the location

address
AddressRequest

If you provide any address object then all address properties need to be included.

address1
string
address2
string
city
string
state
string
zip_code
string
country
string
Responses
204

No Content

Request Sample: Shell / cURL
curl --request PUT \
  --url https://external-integrations.mycase.com/v1/locations/{id} \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "string",
  "address": {
    "address1": "string",
    "address2": "string",
    "city": "string",
    "state": "string",
    "zip_code": "string",
    "country": "string"
  }
}'
