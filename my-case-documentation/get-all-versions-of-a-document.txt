Get All Versions of a Document
GET
https://external-integrations.mycase.com/v1/documents/{id}/versions

Get all versions associated with a specific document.

Request
Path Parameters
id
string
required

The id of the document you want to get / add versions from / to.

Responses
200

OK

string
