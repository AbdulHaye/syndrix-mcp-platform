Get All Notes for a Case
GET
https://external-integrations.mycase.com/v1/cases/{id}/notes

Get all notes associated with a specific case.

Request
Path Parameters
id
string
required

The id of the case you want to get or create notes for.

Responses
200

OK

Headers
Item-Count
number

The total number of results.

Link
string

If there is another page of results, we provides you with the cursor to the next page using page_token. Please reference our pagination documentation for more info.

Body
application/json
application/json
responses
/
200
array of:
id
number

A unique identifier for the note.

subject
string

Subject of the note.

note
string

The body text of the note.

archived
boolean

Whether or not the note is archived.

date
string or null

The date of the note.

client
object or null

The client associated with this note, if there is one.

id
number

object or null

object or null
